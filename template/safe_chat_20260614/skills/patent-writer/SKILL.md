# Patent Writer Skill

专利撰写需要严格遵循中国专利法及其实施细则的格式要求。

## 专利类型选择

| 类型 | 保护内容 | 周期 | 费用 |
|------|---------|------|------|
| 发明专利 | 新技术方案 | 2-3年 | 高 |
| 实用新型 | 实用新技术 | 6-8月 | 低 |
| 外观设计 | 产品外观 | 6-8月 | 低 |

## 专利交底书结构

### 1. 发明名称
简洁明了，不超过 25 个字，避免使用"新型"、"实用"等泛化词。

### 2. 技术领域
明确指出本发明所属或直接应用的技术领域。

### 3. 背景技术（现有技术）
- 说明该技术领域的现状
- 指出存在的问题和缺点
- 引证文献（尽量引用非专利文献）
- 客观描述，不要贬低现有技术

### 4. 发明内容
**核心部分**：
- 解决的技术问题
- 技术方案的完整描述
- 发明的关键点和保护范围
- 有益效果（和现有技术相比的优点）

### 5. 附图说明
- 实用新型必须有附图
- 发明专利必要时也应有附图
- 附图应该清楚显示发明要点

### 6. 具体实施方式
- 结合附图详细说明
- 给出一个以上具体实施例
- 实施例应该能够实现发明的技术方案

### 7. 权利要求书
- 独立权利要求：概括发明的核心技术方案
- 从属权利要求：用附加技术特征进一步限定

## 权利要求撰写要点

```
独立权利要求格式：
一种[产品/方法名称]，其特征在于：[技术特征]

从属权利要求格式：
如权利要求1所述的[产品/方法]，其特征在于：[附加技术特征]
```

## 工作流程建议

对于复杂专利，建议分阶段撰写：

1. **调研阶段**：了解技术背景、现有技术、主要竞争对手
2. **构思阶段**：明确发明要点，确定保护范围
3. **撰写阶段**：按结构顺序撰写，重点是发明内容和权利要求
4. **完善阶段**：检查逻辑一致性，补充实施例

## 输出格式

最终输出应为 Markdown 格式的专利交底书，包含：
- 发明名称
- 技术领域
- 背景技术
- 发明内容
- 附图说明（如有）
- 具体实施方式
- 权利要求书
